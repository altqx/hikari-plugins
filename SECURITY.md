# Security

**A plugin that does harm** (malware, data theft, a hidden network host): email security@hikarisub.org with the plugin's id and version and what you saw. Please don't open a public issue first. We can revoke a version or a whole plugin within minutes, and HikariSub turns it off at its next check.

**A problem in this registry** (a check that can be bypassed, a signing or upload flaw): email security@hikarisub.org, or use GitHub's private vulnerability reporting on this repository.

For any other problem with a plugin, use “Report a problem” on its marketplace page, which opens an issue here.
